# CAN-TEMPO
### Unsupervised CAN Bus Intrusion Detection via Temporal Multi-Period Oscillation Encoding

Official implementation of **CAN-TEMPO**, a period-aware unsupervised intrusion detection framework for automotive CAN bus networks.

---

## Overview

Modern in-vehicle Controller Area Network (CAN) systems exhibit highly periodic communication patterns generated by distributed Electronic Control Units (ECUs). Existing intrusion detection systems often model CAN traffic as one-dimensional temporal sequences, overlooking the intrinsic multi-periodic structure of CAN communications.

CAN-TEMPO addresses this limitation through:
- FFT-based automated period discovery
- Temporal Multi-Periodic Oscillation (TEMPO) blocks
- Multi-scale temporal representations
- Frequency-domain reconstruction supervision
- Statistical consistency regularization

The framework operates fully unsupervised using only benign CAN traffic during training.

---

## Method Summary

CAN-TEMPO transforms raw CAN traffic into structured sliding windows and processes them using stacked TEMPO blocks. The model first extracts dominant temporal periodicities using Fast Fourier Transform (FFT), then folds the signal into period-aware two-dimensional representations. These representations are processed using multi-scale convolutional operations to capture both intra-period and inter-period dependencies.

The final anomaly score combines:
- pointwise reconstruction error,
- statistical consistency,
- spectral reconstruction fidelity.

This design enables the detection of both abrupt and subtle deviations in CAN communication behavior.

---

## Experimental Evaluation

CAN-TEMPO was evaluated on two widely used automotive intrusion detection benchmarks:
- Car-Hacking Dataset (CHD)
- Survival Attack Dataset (SAD)

The framework was tested across multiple attack categories including:
- DoS / Flooding
- Fuzzy attacks
- Gear spoofing
- RPM spoofing
- Malfunction attacks

Experimental results demonstrate that CAN-TEMPO consistently outperforms representative recurrent, convolutional, graph-based, and transformer-based baselines while maintaining strong robustness across attack types and vehicle platforms.

---

## Main Contributions

- Explicit modeling of periodic CAN communication structure
- FFT-based automated period discovery
- Multi-scale temporal feature extraction
- Frequency-aware reconstruction supervision
- Strong cross-vehicle generalization
- Stable detection performance with low false positive rates

---

## Datasets

### Car-Hacking Dataset (CHD)
The CHD benchmark contains CAN bus recordings collected from a real vehicle under multiple injection attack scenarios, including DoS, Fuzzy, Gear spoofing, and RPM spoofing attacks.

### Survival Attack Dataset (SAD)
The SAD benchmark contains CAN recordings collected from multiple vehicles under Flooding, Fuzzy, and Malfunction attacks.

Unlike datasets that do not preserve timestamp information, both CHD and SAD retain the temporal structure required for modeling inter-arrival dynamics and periodic communication behavior central to CAN-TEMPO.
